## Discover and Access Data

The catalogue hosts New Zealand's Antarctic and Southern Ocean data with a metadata record, and provides access to Antarctic Science Platform and Antarctica New Zealand supported data.

## About

The catalogue is a distributed metadata management system that creates and harvests metadata from multiple sources, rather than hosting data directly. By implementing ISO 19115 metadata standards, it ensures consistency and interoperability, effectively creating a virtual data centre that enables seamless discovery, access, and use across distributed, domain-specific repositories.
